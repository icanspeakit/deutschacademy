# Content engine — ledger (deutschacademy)

Append-only. **One line per completed batch.** A batch is not complete until its line exists here;
a fresh session reads this file plus the stream's spec in `CONTENT-ENGINE-PROMPT.md` — never the
whole conversation, and never a lexicon level file (hard rule 6).

Created 2026-09-17, on the first batch run under `CONTENT-ENGINE-PROMPT.md`.

## Reading the columns

- **produced** — what the batch added, in the units or items the stream counts in.
- **gate result** — the stream's own gate number, as the tool reported it, not a judgement.
  Stream 1's is `unresolved` from `fetch-wiktionary` (abort above 3 per 125), **not**
  `no German section`, which is a Wiktionary coverage fact about long compounds, not a signal
  about the generated words.
- **validator** — `node scripts/validate-lexicon.mjs` exit state, plus `pnpm build`.
